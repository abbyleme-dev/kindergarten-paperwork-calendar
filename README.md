# 幼兒園文書行事曆

幼兒園一學年會遇到的事件（新生入園、校外教學、運動會、畢業典禮、孩子受傷告知、停課通知等）與每份文件的 AI 提示詞。點一個事件、填一次活動資料卡，提示詞會自動帶入，複製後貼到 ChatGPT、Gemini 或 Claude 就能使用。

- 填寫的資料只存在使用者自己的瀏覽器，不會上傳。
- 範例資料（日期、人數、地點）皆為虛構；請勿輸入幼兒或家長的真實姓名與個人資料。
